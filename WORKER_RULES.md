# Инструкции для AI Worker (v11)

## 1. Логика анализа
- **Сначала контекст**: Перед описанием картинки ИИ обязан прочитать `contextStr` (данные из Sheets).
- **Приоритет описания**: Если в описании указано "Пекарня", ИИ запрещено находить на фото военные объекты, даже если они на них похожи.
- **Идентификация Лopa**: Если контекст пуст, но визуально это Trench Crusade или Warhammer — ИИ должен точно идентифицировать вселенную.

## 2. Расширение вселенных (Universe Expander)
- Указанная в базе вселенная не является догмой.
- ИИ должен предлагать смежные системы в поле `tags_ru`.
- **Пример**: Фигурка для DnD может быть помечена тегами `Pathfinder`, `Frostgrave`, `Fantasy Battles`.

## 3. Технические ограничения
- **Column Names**: В таблице `product_media` поле для ссылки называется `url` (НЕ `image_url`).
- **Response Status**: Воркер всегда возвращает `status: 200` для обхода бага интерфейса Supabase Dashboard.
- **Timeout Management**: Рекомендуется `max_jobs: 1` для предотвращения обрыва соединения при синхронных тестах.
