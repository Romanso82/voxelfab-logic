# START_CHAT_PROMPT.md

## 📌 Как работать с этим проектом

Перед началом каждого диалога:

1. Открой PROJECT_STATE.md
2. Открой DATABASE_STATE.md
3. Открой WORKER_RULES.md
4. Открой AGGREGATE_RULES.md
5. Открой CRON_PIPELINE.md
6. Открой ROADMAP_AI.md

Используй их как единственный источник истины.

---

## 🎯 Цель системы

Автоматическая AI‑индексация миниатюр VoxelFab:

Sheets → Supabase → AI Worker → AI Aggregate → Bot

---

## ⚙️ Основные принципы

- Не выдумывать сущности, которых нет в исходных данных
- Главная картинка = источник состава набора
- Остальные картинки = расшифровка компонентов
- Террей ≠ персонажи
- 1 персонаж не дублируется

---

## 🧠 Самообучение

Если боту:
- не хватает данных
- низкая уверенность
- нет атрибута

→ писать в `ai_recommendations`

---

## 🚀 Текущий pipeline

1. vf-sync-catalog → обновляет товар
2. выставляется флаг на переиндексацию
3. Worker (батчами)
4. Aggregate (батчами)

---

## ⛔ Важно

Никогда:

- не ломать существующие поля
- не менять структуру без фиксации в DATABASE_STATE.md
- не запускать бесконечные ретраи
